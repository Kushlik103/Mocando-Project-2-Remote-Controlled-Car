# Mocando-Project-2-Remote-Controlled-Car
This repository is for my second Arduino project which is remote control car using Arduino, L298n motor driver, batteries, dc motors, IR remote and sensor and a lot of jumper wires.
This project took me more than 5 hours and a lot of logical thinking.
It is a 2 wheeler car with which goes in all direction.
On the first day of building this I faced an tiny problem in the wiring for which reason i burned one of my battery holders and also injured my finger.
On the second day with more testing and debugging I didn't had the same problem and after many different tests on each motor I finally succeeded.
Then came the coding part which took me more than 30 mins
It is fun to play and also make me proud when I see it.
